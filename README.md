# Rafina Storybox

Katalog produk mudah alih untuk Rafina Storybox. Dibina dengan HTML, CSS dan JavaScript biasa supaya boleh dihoskan secara percuma di GitHub Pages.

## Kandungan
- `index.html` — katalog dan maklumat pakej A–K
- `styles.css` — gaya responsif sky-blue dan white, termasuk animasi scroll
- `script.js` — pautan WhatsApp dengan pakej terpilih
- `assets/products/` — foto produk yang disediakan

## Semak secara setempat
Buka `index.html` dalam pelayar. Tiada pemasangan diperlukan.

## GitHub Pages
Dalam repo, buka **Settings → Pages**, pilih **Deploy from a branch**, pilih branch `main` dan folder `/(root)`, kemudian tekan **Save**. Tunggu sehingga GitHub Pages menunjukkan status berjaya sebelum kongsi pautan.
